
# StockPilot

StockPilot is an inventory management website designed to help small businesses organize products, manage orders, maintain customer information, and review business analytics.

## Target Audience

Small business owners and inventory managers.

## Pages

- Home
- Products
- Orders
- Customers
- Analytics

## Technologies

- HTML
- CSS
- JavaScript
- Git and GitHub
