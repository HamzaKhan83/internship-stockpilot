About StockPilot

A simple inventory system built during the Verstech Web Development Internship.

Our purpose

Small businesses often track stock in notebooks or scattered spreadsheets, which leads to missed reorders and lost sales. StockPilot gives them one clear place to see what they have, what is running low and what it is worth.

🎯

Purpose

Help owners track products and avoid running out of stock.

👥

Target audience

Shop owners, office managers, school stores and small warehouse teams.

🚀

Goal

Make inventory control fast, visual and easy enough for anyone to use.

Technologies used

Built from scratch with no front-end frameworks.

HTML5

Semantic structure with header, nav, main, section and footer.

CSS3

Flexbox, Grid, CSS variables, media queries and a dark mode theme.

JavaScript

DOM, localStorage, fetch API, form validation and CSV export.

Public API

The DummyJSON API provides the live supplier catalog on the home page.

Node.js + Express

A small backend receives and stores messages from the contact form.

Git & GitHub

Version control for the source code, with deployment from the repository.
